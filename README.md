# 🎓 Sistema Escolar - Complejo Educativo Thomas Jefferson

Sistema web de gestión académica desarrollado para el **Complejo Educativo Thomas Jefferson** en El Salvador. Permite la administración completa de estudiantes, control de asistencia, registro de calificaciones y generación de reportes institucionales.

## 🌟 Características Principales

### 🔐 Seguridad y Autenticación
- **Modo oscuro predeterminado** para mejor experiencia visual
- **Código de seguridad institucional** (CLASES26$COED) para acceso
- **Autenticación Firebase** con recuperación de contraseña por email
- **Control de roles**: 5 administradores y docentes
- **Validación de correo institucional** (@clases.edu.sv)

### 👨‍🏫 Módulo Docente
- **Dashboard personalizado** con métricas en tiempo real
- **Gestión de alumnos**: Registro, edición y eliminación por grado/sección
- **Control de asistencia diario** con estadísticas por género
- **Registro de calificaciones** por 4 períodos académicos
- **Sistema de notas tipo Excel** con actividades dinámicas
- **Cálculo automático de promedios**

### 👨‍ Módulo Administrativo
- **Panel de control** con estadísticas globales
- **Generación de cuentas docentes** con credenciales automáticas
- **Visualización de notas** por grado y sección
- **Reportes en PDF** de calificaciones y asistencia
- **Gestión de múltiples grados** (Parvularia a 3° Año Bachillerato)

### 📊 Funcionalidades Avanzadas
- **Diseño responsive** (mobile-first)
- **Tiempo real** con Firebase Firestore
- **Exportación a PDF** de reportes académicos
- **Gráficos interactivos** de asistencia y rendimiento
- **Búsqueda en tiempo real** en listas de estudiantes
